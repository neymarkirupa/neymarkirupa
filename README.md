## Founder of ElevenSeven

I am building **[ElevenSeven](https://github.com/neymarkirupa/elevenseven)**, a
modern football jersey startup with an animated storefront and a Node.js
e-commerce backend for checkout, order management, delivery tracking, and
admin operations.

## What I Build

- **ElevenSeven** - A jersey shopping experience with cart, WhatsApp ordering,
  Razorpay checkout, Shiprocket delivery, and order tracking.
- **AI and automation workflows** - Practical tools that reduce repetitive work.
- **FastAPI applications** - Backend services for events, databases, and APIs.
- **Python projects** - Dijkstra/graph tools and desktop utilities.
